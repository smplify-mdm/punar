# Application icon sources

These SVG marks are application identity content, not Punar interface icons.
They come from [Simple Icons](https://github.com/simple-icons/simple-icons) at
commit `1bd24ad0645f18ec68b17a087daa5649644bd303`, whose icon data is released
under CC0 1.0. Each path is unchanged; Punar adds only the brand color so the
monochrome source remains legible in both shell moods.

`chatgpt.svg` uses the OpenAI mark from Simple Icons 14.0.0 (CC0 1.0), with
the title changed to ChatGPT to match the catalog product name. `claude.svg`
uses the Claude mark from the pinned Simple Icons commit above.

Names and logos may still be trademarks of their respective owners. They are
used only to identify the application offered by the catalog.

`slack.svg` is the Slack icon published on Wikimedia Commons at
`https://commons.wikimedia.org/wiki/File:Slack_icon_2019.svg`; its four paths
and colors are unchanged.

The 128×128 PNG icons for Apostrophe, DBeaver Community, Dev Toolbox, Logs,
HTTPie, KeePassXC, Meld, Mission Center, Podman Desktop, Postman, VSCodium, and
Wireshark are the application icons published in Flathub's x86_64 AppStream
repository at `https://dl.flathub.org/repo/appstream/x86_64/icons/128x128/` on
2026-08-28. They are copied byte-for-byte and used only for product identity.
